Validação de Extratos — Stoic Capital
======================================

Aplicação Flask para normalizar, classificar e validar extratos bancários
de múltiplas instituições financeiras brasileiras.

.. note::
   Esta documentação cobre o **comportamento interno** do sistema. Para
   instruções de uso e operação, ver :doc:`operacao`. Para uma visão geral
   rápida, ver o `README na raiz do repositório <https://github.com/LuisStoic/extratos_Manta#readme>`_.
